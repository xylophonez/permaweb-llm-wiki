# Resources

This folder holds repo-scoped examples that were added when a topic page needed a concrete artifact but the original source repo was out of scope.

Use these as examples and templates, not as the primary synthesis layer.

- `arweave/`: web app deploy examples, GraphQL reference/snippets, build-pattern notes, and wallet/browser integration snippets
- `permawebos/`: seed-release checklist for LLM-friendly forkable apps
